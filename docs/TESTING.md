# 確認手順

- プロトタイプ 1（オーバーレイの表示）：1.21.11 と 26.3 で確認済み
- プロトタイプ 2（メニューの操作）：1.21.11 と 26.x で確認済み
- 高精細のズーム・キーの変更・設定の保存：下の「ズームとキーの変更で確認すること」
- プロトタイプ 3（F3+C によるウェイポイント）：下の「ウェイポイントで確認すること」
- キーの置き換え：下の「キーの置き換えで確認すること」
- インストーラー：下の「インストーラーで確認すること」
- ゲーム内ブラウザ：下の「ブラウザで確認すること」

## 準備

1. `reminedog.dll` を入手する（[README](../README.md#dll-の入手)）
2. パスに日本語も空白（スペース）も含まない場所に置く（例：`C:\reminedog\reminedog.dll`。`C:\Program Files` は不可）
3. 確かめたいインスタンスの JVM 引数に `-agentpath:C:\reminedog\reminedog.dll` を追加する

## インストーラーで確認すること

`C:\reminedog\reminedog-installer.jar` をダブルクリックして開く。インストーラーは本物のランチャーの設定ファイルを書き換えるので、試すのは次のインスタンスだけにする（スピードラン用のインスタンスは選ばない）。

- Prism Launcher の 1.21.11 と 26.3（今は `-agentpath:C:\reminedog\reminedog.dll` が入っている。26.3 は `=log=debug` 付き）
- MCSR Launcher の Server（1.21.11。今はランチャーの Java の設定を使っている）

DLL は「PC にある DLL を使う」で `C:\reminedog\reminedog.dll` を選ぶ（「GitHub から最新版をダウンロードする」は、今はリリースがないので失敗する）。

### 開く

- [ ] ダブルクリックで開き、Windows のダークモード／ライトモードに合った色で出る
- [ ] 一覧に Prism Launcher の 3 つと MCSR Launcher の 5 つのインスタンスが出て、バージョンの列が正しい
- [ ] 「状態」が、Prism の 1.21.11 と 26.3 は「導入済み」（緑）、ほかは「未導入」
- [ ] 「保存するフォルダ」を `C:\Program Files\reminedog` にすると、下に赤字で「パスに空白（スペース）が入っています」と出る。`C:\reminedog` に戻す

### ランチャーが起動しているとき

- [ ] Prism を起動したまま、Prism の 1.21.11 にチェックを付けて「アンインストール」を押すと、「次のランチャーが起動しています：Prism Launcher」と出る。「いいえ」を押すと何も変わらない（ログに何も出ない）
- [ ] 同じく MCSR Launcher を起動したまま Server で試すと、「MCSR Launcher」と出る

### Prism Launcher

Prism を閉じてから行う。

- [ ] 1.21.11 にチェックを付けて「アンインストール」：ログに「Prism Launcher / 1.21.11：外しました（JVM 引数：なし）」、「状態」が「未導入」になる
- [ ] Prism を開き、1.21.11 の「編集」→「設定」→「Java」の「JVM 引数」が空になっている。起動するとオーバーレイが出ない。Prism を閉じる
- [ ] 1.21.11 で「インストール」：「追加しました（JVM 引数：-agentpath:C:\reminedog\reminedog.dll）」。Prism の「JVM 引数」に入っていて、起動するとオーバーレイが出る
- [ ] 26.3 で「インストール」：「すでに入っています」。Prism の「JVM 引数」の `=log=debug` が残っている
- [ ] 「PC にある DLL を使う」のファイルを `C:\reminedog\reminedog2.dll`（なければ `C:\reminedog\reminedog.dll` をコピーして作る）にすると、26.3 の「状態」が「別の DLL：C:\reminedog\reminedog.dll」になる。26.3 で「インストール」すると `-agentpath:C:\reminedog\reminedog2.dll=log=debug` になる。`C:\reminedog\reminedog.dll` に戻して、もう一度「インストール」する

### MCSR Launcher

MCSR Launcher を閉じてから行う。

- [ ] Server で「インストール」：「追加しました（JVM 引数：-agentpath:C:\reminedog\reminedog.dll）」。
  MCSR Launcher で Server のインスタンスの設定を開くと、Java の設定がランチャーのものからインスタンスのものに切り替わり、Java・メモリーがランチャーと同じ値で、JVM 引数に `-agentpath:...` が入っている
- [ ] Server を起動するとオーバーレイが出る（1.21.11 なのでオーバーレイが出るはず。出なければ `<インスタンス>\.minecraft\reminedog\reminedog.log` を送ってほしい）
- [ ] MCSR Launcher を閉じ、Server で「アンインストール」：「外しました（JVM 引数：なし）」。起動してオーバーレイが出ない
- [ ] 元に戻したいなら、MCSR Launcher の Server の設定で、Java の設定を「ランチャーの設定を使う」に戻す（インストーラーは戻さない）

### ダウンロード

- [ ] 「GitHub から最新版をダウンロードする」のまま「インストール」：ログに「ダウンロードできませんでした：GitHub（bafv4/reminedog）に公開されているリリースがありません」と出て、「インスタンスは変えていません」のダイアログが出る。「状態」は変わらない

### 最新版に更新

今はリリースがないので、置き換える前の確認と、失敗したときに何も変えないことだけを確かめる。ゲームは閉じておく。

- [ ] 「未導入」のインスタンスだけにチェックを付けて「最新版に更新」：「チェックしたインスタンスには、置き換えられる reminedog が入っていません。」と出る。ログに「…：reminedog が入っていないので飛ばします」
- [ ] Prism の 1.21.11 と 26.3 にチェックを付けて「最新版に更新」：確認に「・C:\reminedog\reminedog.dll（Prism Launcher / 1.21.11、Prism Launcher / 26.3）」のように、DLL が 1 行にまとまって出る。「いいえ」を押すと何も起きない
- [ ] もう一度押して「はい」：ログに「ダウンロードできませんでした：GitHub（bafv4/reminedog）に公開されているリリースがありません」、ダイアログに「最新版をダウンロードできませんでした。DLL は変えていません。」。`C:\reminedog\reminedog.dll` の更新日時は変わらず、ゲームも今までどおり起動する

## ブラウザで確認すること

1.21.11（全画面、Sodium あり）と 26.3 の両方で確かめてほしい。手元では、テスト用のプログラム（GLFW、ウィンドウ）で表示・PageDown・↓・メニューからの表示とページのクリック・文字入力・Enter での検索まで確かめた。

### 準備

1. ゲームを閉じてから、新しい `reminedog.dll` を `C:\reminedog\` に置く（置いてある）
2. ゲームを起動し、ワールドに入る。メニュー（Ctrl+I）の「ブラウザ」の欄を押して開く

### 表示

- [ ] 「表示する」を押すと、画面の右上に枠が出て、数秒で Google のページが出る。欄の状態が「表示中」になる
- [ ] メニューを閉じても、ページは同じ位置に出たまま。視点の操作・移動・攻撃などはふつうにできる
- [ ] 1.21.11 の全画面で、表示してもゲームが最小化されたり、ちらついたりしない
- [ ] ページを出しているときと出していないときの fps（F3 画面）の違い。記事を出しているときと、動画を再生しているとき

### メニューを開いているときの操作

- [ ] ブラウザの窓のタイトル（「ブラウザ：…」）をドラッグすると窓が動く。ページの右下の角（斜めの線）をドラッグすると大きさが変わる
- [ ] メニューを閉じると、ページは窓の中にあったのと同じ位置・大きさで出る。もう一度開いても位置は変わらない
- [ ] メニューを閉じているときは、ページを動かしたり大きさを変えたりできない（マウスはゲームに行く）
- [ ] アドレス欄を押して `youtube.com` と打ち、Enter で YouTube が開く。言葉（例：`マインクラフト 村人`）を入れると Google の検索結果が開く
- [ ] YouTube の検索欄を押し、IME で「マインクラフト」と打って確定し、Enter で検索できる（変換中の文字はページに出ないが、確定すると入る）
- [ ] 動画を押すと再生され、音が出る。ホイールでページがスクロールする。⏴（戻る）・⏵（進む）・⟳（再読み込み）が効く
- [ ] ページを右クリックしても、メニューなどは出ない
- [ ] **全画面のゲームで、ページを押したり文字を打ったりしても、ゲームが最小化されない（フォーカスが外れない）**
- [ ] 窓の × を押すと非表示になり、欄が「非表示（動画は一時停止している）」になる

### ゲーム中のキー

- [ ] Wikipedia の長い記事（例：`ja.wikipedia.org/wiki/Minecraft`）を出してメニューを閉じ、PageDown・PageUp で 1 画面ずつスクロールする（押し続けると続けてスクロールする）
- [ ] YouTube の動画を出してメニューを閉じ、↓ で一時停止・再生、← で 10 秒戻る、→ で 10 秒進む。そのたびに画面の上のほうに「一時停止　1:23 / 10:00」「10 秒戻した　…」のように出る
- [ ] チャット（26.3 は Backspace、1.21.11 は T）を開いて ← → を押すと、チャットの入力欄のカーソルが動く（動画は動かない）
- [ ] F3 を押したまま ↓ や PageDown を押しても、reminedog は反応しない
- [ ] 「非表示にする」で隠した後は、↓ を押しても通知は出ない（ゲームに渡る）
- [ ] 動画のない記事で ↓ を押すと「ページに動画がありません」と出る

### 表示／非表示のキー

- [ ] 欄のキーの表で「ブラウザの表示／非表示」のボタンを押してから Y を押すと、Y が割り当てられる
- [ ] 動画を再生した状態でメニューを閉じ、ゲーム中に Y を押すと隠れて動画が止まる。もう一度 Y を押すと出て、続きから再生される
- [ ] チャットを開いて Y を打つと、チャットに y が入る（ブラウザは変わらない）
- [ ] 「外す」を押すと「なし」に戻り、Y はゲームに渡る

### そのほか

- [ ] 「ページの拡大率」を動かすと、ページの文字が大きく・小さくなる（拡大しても、クリックした場所が合っている）
- [ ] 「不透明度」を下げると、メニューを閉じているときだけページが透ける
- [ ] YouTube の動画の説明にある外部のリンク（新しいタブで開くもの）を押すと、同じ画面で開き、別のウィンドウは出ない
- [ ] 「終了」を押すと、タスク マネージャーの詳細から `msedgewebview2.exe` がなくなる。もう一度「表示する」で、最後に見ていたページが開く
- [ ] ゲームを再起動して「表示する」を押すと、前回の位置・大きさ・最後に見ていたページで開く。YouTube にログインしていれば、ログインしたまま
- [ ] 26.3 と 1.21.11 で、同じログインが使える（`%LOCALAPPDATA%\reminedog\WebView2` を共有している）

### ログ

- [ ] `reminedog.log` に `browser: starting`・`browser: ready`・`browser: first picture ...` が出る。`browser:` の行に `[WARN]`・`[ERROR]` があれば送ってほしい
- [ ] ログにページの URL（クエリを含むもの）が出ていない（`=log=debug` でもホスト名だけ）

## キーの置き換えで確認すること

1.21.11 と 26.3 の両方で確かめてほしい。1.16.1 は対象外（手元のテスト用のプログラムだけで確かめている）。

置き換えるキーには、両方のインスタンスでゲームの操作に割り当てていないキー（B・H・N・U・Y。B・H・N は F3 との組み合わせにだけ使われている）を使う。操作は名前で書く。今のキー設定では、「アイテムを捨てる」は 1.21.11 が Q、26.3 が C。

### 準備

1. ゲームを起動し、メニュー（Ctrl+I）の「キーを元に戻す」を押す（メニューを開く Ctrl+I、ズーム Z、ウェイポイントを記録 J、現在地を更新 K になる）
2. 確かめるワールドに入り、`/gamemode` を使えるようにしておく（「ウェイポイントで確認すること」の準備の 3 と同じ）。掘る・食べるの確認はサバイバルで、ほかはクリエイティブでよい。ホットバーに、捨ててよいアイテムのスタック（土など）と弓を置く
3. 1 つの元のキーには置き換えを 1 つしか作れない。同じ元のキーで別の置き換えを試すときは、前の行を「削除」してから追加する。試し終わったら、「削除」で消すか「キーの置き換えを使う」を外しておく
4. **注意**：マウスのボタン4 → F3 を試している間は、マウスのボタン4 と C を一緒に 10 秒押し続けない。F3+C を押し続けたときと同じく、Minecraft のデバッグ用のクラッシュでゲームが落ちる（26.3 では C が「アイテムを捨てる」なので、長押ししやすい）

### メニューで追加する

- [ ] メニューの「ウェイポイント」の下に「キーの置き換え（0 個）」の欄がある。押して開くと、「Minecraft に届くキーを別のキーやマウスのボタンに置き換える。…」の説明、「キーの置き換えを使う」（チェックが入っている）、「置き換えはまだない」、「追加」が出る
- [ ] 「追加」を押すと「置き換えるキーかマウスのボタンを押す（Esc で取り消し）」と出る。マウスのボタン4 を押すと「マウスのボタン4 → ？ ゲームに送るキーかマウスのボタンを押す（Esc で取り消し）」と、「左クリック」「右クリック」「ホイールクリック」「取り消し」のボタンが出る
- [ ] 続けて F3 を押すと、「マウスのボタン4 → F3（オーバーレイの切り替え・デバッグ修飾キー）」の行が増え、見出しが「キーの置き換え（1 個）」になる。F3 を離しても、メニューの裏で F3 画面は開いたり閉じたりしない（メニューを閉じても、F3 画面は押す前のまま）
- [ ] 元のキーを待っている間と、置き換え先を待っている間のどちらでも、Esc か「取り消し」で取り消せる（何も増えない。Esc でメニューは閉じない）
- [ ] 「追加」→ Z と押すと、「Z は「ズーム」に使っているので置き換えられない」と出て、待つのをやめる。J なら「J は「ウェイポイントを記録」に使っているので置き換えられない」
- [ ] 「追加」→ マウスのボタン4 と押すと、「マウスのボタン4 はもう置き換えている」と出る
- [ ] 「追加」→ U → U と押すと、「同じキーには置き換えられない」と出て、置き換え先を待ったままになる。続けて「左クリック」のボタンを押すと「U → 左クリック（攻撃する／壊す）」の行が増える。その直後に Ctrl+I でメニューを閉じられる
- [ ] 「追加」→ Y → Y と押して「同じキーには置き換えられない」が出たところで、Esc か「取り消し」を押すと、その注記も消える（メニューを閉じて開き直しても出ていない）
- [ ] 「キー」の欄でズームのボタンを押してから U を押すと、「U は置き換えに使っている」と出て、ズームのキーは変わらない
- [ ] 「キー」の欄でズームをマウスのボタン5 に変えてから、「追加」→ Z → Y と押す（Z が空いたので追加できる）。「キーを元に戻す」を押すと、ズームはマウスのボタン5 のままで「Z は置き換えに使っている」と出る（ほかの 3 つは Ctrl+I・J・K に戻る）。確かめたら Z → Y の行を「削除」し、もう一度「キーを元に戻す」でズームを Z に戻す
- [ ] U → 左クリック の行の「削除」を 1 回押すと、その行が消える
- [ ] 「追加」→ 左 Ctrl → F4 と押すと、行の下に「左 Ctrl は「メニューを開く」（Ctrl+I）の修飾キーにも使っている」と警告が出る（確かめたら、この行も消す）
- [ ] 「キーの置き換えを使う」を外すと行が灰色になり、どの置き換えも効かなくなる。付け直すと戻る
- [ ] ゲームを再起動しても置き換えが残っている。ゲームフォルダの `reminedog/settings.json` に `"rebinds"` がある
- [ ] IME をオンにした状態で「追加」を押し、文字のキー（U など）を押すと、元のキーとして取れるか（取れなければ知らせてほしい）
- [ ] ゲームのウィンドウを小さくして（854×480 ほど）メニューを開き、「キーの置き換え」と「ウェイポイント」の欄を開くと、メニューは画面に収まり、中をスクロールできる。そのままウィンドウを最大化すると、メニューが画面に合わせて伸びる（中身が短ければ中身の高さまで）。小さくすると、また画面に収まる
- [ ] メニューのタイトルバーをダブルクリックしても、メニューは畳まれない

### マウスのボタン4 → F3

- [ ] ゲーム中にマウスのボタン4 を押して離すと、F3 画面が開く。もう一度押して離すと閉じる
- [ ] マウスのボタン4 を押したまま B を押すと、当たり判定の枠が出る（F3+B）。もう一度で消える
- [ ] マウスのボタン4 を押したまま C を短く押すと、チャットに「［デバッグ］：クリップボードに座標をコピーしました」（1.21.11 のように英語のゲームでは "[Debug]: Copied location to clipboard"）と出て、メモ帳に座標を貼り付けられる。メニューの「現在地」も更新される
- [ ] マウスのボタン4 を押している間は、J・K・Z を押しても reminedog は反応しない（F3 を押しているときと同じく、ゲームに渡る）
- [ ] マウスのボタン4 を押したまま Ctrl+I でメニューを開き、押したまま「現在地を記録」を押すと、「マウスのボタン4（F3 に置き換え）を押している間は座標を取得できない」と出る。メニューを閉じてマウスのボタン4 を離せば（このとき F3 画面が切り替わることがある）、J で記録できる

### CapsLock → 左 Ctrl

CapsLock を押すたびに大文字の入力が切り替わる（Windows が処理するので止められない）。終わったら CapsLock のランプを消しておく。

- [ ] 1.21.11：CapsLock を押したまま W を押すと走る（ダッシュが左 Ctrl）。CapsLock を押したまま Q を押すと、手に持ったスタックをまとめて捨てる
- [ ] 26.3：CapsLock を押したまま C を押すと、スタックをまとめて捨てる。置き換えている間は、CapsLock の「アイテムをオフハンドと交換」は動かない
- [ ] 26.3：CapsLock を押したまま J を押すと、「CapsLock（左 Ctrl に置き換え）を押している間は座標を取得できない」と出て、何も捨てない（C に「アイテムを捨てる」があるので、Ctrl を押している間は F3+C を送らない）

### キーとマウスのボタンの組み合わせ

- [ ] H → 左クリック：サバイバルで H を押し続けると、石などを最後まで掘れる（途中で掘り直しにならない）
- [ ] 26.3：H → 左クリック のまま、ポーズ画面の「セーブしてタイトルへ戻る」でタイトルに戻り、ワールドの一覧の「選択したワールドで遊ぶ」を左クリックして入り直す（一覧のダブルクリックでも試す）。入ってすぐ H を押すと、1 回目から殴る・掘る（効かなければ、何回目から効いたかを知らせてほしい）
- [ ] N → 右クリック：弓を持って N を押し続けると引き絞り、離すと矢を放つ（サバイバルで空腹なら、食べ物を食べられる）
- [ ] マウスのボタン5 → 「アイテムを捨てる」のキー：押し続けても 1 個しか捨てない（マウスのボタンはリピートしない）
- [ ] Y → 「アイテムを捨てる」のキー：押し続けている間は、続けて捨てる（キーのリピートはそのまま届く）

### 画面、メニュー、フォーカス

- [ ] U → W：U を押すと前に歩く。押したまま E でインベントリを開いて閉じると、押している間は歩き続け、離すと止まる。インベントリの中で U を離してから閉じると、歩いていない
- [ ] 左 Shift → W（元のキーにゲームの操作があるとき）：左 Shift を押すと、スニークせずに前に歩く。押したまま E でインベントリを開いて閉じても、スニークしない

### ログ

| `agent loaded` | JVM が DLL を読み込んだ |
| `DLL loaded: ...glfw.dll` | LWJGL が GLFW を読み込んだ場所（資料の未検証の前提 1） |
| `GLFW hooks installed` | `glfwSwapBuffers` をフックできた |
| `OpenGL hooks installed` | 高精細のズームのために `wglGetProcAddress` をフックできた |
| `F3+C: clipboard hooks ready` | 座標を取るためのフック（クリップボード、キー）が揃った。`F3+C: hooks missing; no waypoints` なら、ウェイポイントは使えない |
| `settings: ...` | 設定ファイルの場所と、メニュー・ズーム・記録・更新のキー、キーの置き換えの数（`rebinds N`。「キーの置き換えを使う」が外れていれば `rebinds off (N)`） |
| `rebinds: N active (...)` | 実際に使うキーの置き換え（`元 -> 先`、名前は 26.x のもの）。下の `left out` の行で除いたものと、キーの状態を読む関数をフックできなかったときのキーボードのキーを元にするものは入らない。全体がオフなら `rebinds: off (...)` の後に `rebinds: 0 active ()` |
| `rebinds: left out ...` | 使えないので除いた置き換えと、その理由（メニューの行の下にも出る）。この版のゲームが扱えないキーは `the game's window library has no <名前>` |
| `settings: some rebinding values in ... cannot be read; copied the file to ...` | settings.json の置き換えに読めない値や項目があったので、読み飛ばし、ファイルを `settings.rebinds-<数字>.json` に写した（その前の `settings: dropped the rebind ...` などの行が、読み飛ばしたもの） |
| `rebinds: the game's key state reads are not hooked; keys are not rebound` | ゲームがキーの状態を読む関数をフックできなかったので、キーボードのキーを元にする置き換えは使わない（マウスのボタンは使う） |
| `options.txt: ...` | Minecraft の F3+C のキー（修飾キー、座標のコピー、クラッシュ）と、座標のコピーと同じキーに割り当てたほかの操作 |
| `world: ...` | 今のワールド（シングルプレイはフォルダ名、マルチプレイはサーバー）。`not in a world` はワールドの外、`unknown` は判定できていない |
| `F3+C: requested (...)` / `F3+C: location captured (...)` | 座標の取得を送った／座標が取れた（`manual` は自分で押した F3+C） |
| `F3+C: refused (...)` | ゲームが F3+C を受け付けなかった（デバッグ情報の制限） |
| `waypoints: waypoint N recorded` | 地点を記録して保存した（`renamed`・`removed` は名前の変更と削除） |
| `game GL: ...` | ゲームのコンテキスト（バージョン、GPU、core／compatibility） |
| `pixel format ...` | ウィンドウのピクセルフォーマット |
| `overlay GL: ...` | 自前のコンテキスト（資料の未検証の前提 5） |
| `overlay: first frame rendered` | 1 フレーム目を描けた |
| `[ERROR]` / `[WARN]` | 問題があった。内容を送ってほしい |

## Minecraft 26.x について

26.x は GLFW ではなく SDL3 でウィンドウを作り、OpenGL で描いている。reminedog は SDL3 の `SDL_GL_SwapWindow` をフックして、1.21 以前と同じようにオーバーレイを描く。
上の確認項目は 26.x でも同じ。ログには次の行が出る。

| 行 | 意味 |
|---|---|
| `SDL3 loaded` / `SDL3 hooks installed` | SDL3 を検出し、フックできた |
| `SDL_CreateWindow(... [OpenGL, hidden])` | 描画用の非表示の補助ウィンドウ。ここにはオーバーレイを出さない |
| `SDL_CreateWindow("Minecraft 26.x", ... [OpenGL])` | ゲームのウィンドウ |
| `renderer: OpenGL via SDL3` | OpenGL のコンテキストが作られた（Vulkan なら `Vulkan via SDL3` と出る。その場合はまだ描けない） |
| `window system: SDL 3.x.x` | オーバーレイが SDL3 のウィンドウに付いた |
